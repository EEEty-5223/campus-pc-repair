# 校园电脑维修预约小程序

这是一个能直接导入微信开发者工具运行的第一版原型，面向校园电脑维修社团。它不依赖 npm、服务器、数据库或真实 AppID，重点是先演示完整业务流程。

## 现在能做什么

- 用户浏览可预约的维修服务
- 填写姓名、手机号、校内地点、设备、故障和预约时间
- 在“我的预约”查看详情与处理状态
- 提交后状态为“预约中”，社团确认后显示“预约成功”
- 社团成员可在后台对预约进行文字回复，用户在详情页和列表查看
- 在待确认阶段取消预约
- 在待确认阶段修改预约信息
- 社团成员通过演示后台依次执行“接单 → 开始维修 → 完成”
- 详情页显示完整处理时间线
- 社团后台支持状态筛选和预约统计
- “我的预约”可按全部、处理中和已结束筛选
- 相同手机号、日期和时段的处理中预约会触发重复提醒
- 空后台可以一键生成三条明确标记的非真实演示预约
- 预约数据保存在当前开发工具或当前微信设备的本地缓存

## 3 分钟运行

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择“小程序”项目并导入本目录：`D:\app\codex\1\电脑维修预约小程序`。
3. AppID 选择“测试号”或使用自己的小程序 AppID。
4. 点击“编译”。
5. 从首页提交一条预约，再打开首页底部的“社团成员演示后台”更新状态。

当前电脑已经安装微信开发者工具 `2.02.2608070`，项目配置中已写入开发者工具提供的测试号，并关闭请求域名校验；因为本版没有任何网络请求，这不会影响演示。换到其他电脑时，可以继续选择测试号，也可以替换为社团自己的小程序 AppID。

## 第一版的明确限制

1. 数据只在本机，不会同步到其他同学或社团成员的手机。
2. 演示后台没有登录和权限控制，不能直接用于正式发布。
3. 没有图片上传、消息通知、排班冲突检查和评价功能。
4. 信息使用说明是占位内容，正式发布前需要社团负责人按真实情况补全并配置微信公众平台隐私保护指引。

## 下一版建议

第二版优先接入微信云开发：把 `utils/appointments.js` 的本地读写替换为云函数和云数据库，增加基于 openid 的用户隔离、管理员名单与服务端状态校验。页面层和状态名称可以继续复用。
